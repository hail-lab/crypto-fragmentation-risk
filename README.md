# Cross-Exchange Fragmentation and Stablecoin Fragility  
Replication Code

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21792917.svg)](https://doi.org/10.5281/zenodo.21792917)

This repository contains the replication code for the empirical analysis in the paper:

**"Does Cross-Exchange Fragmentation Distort Cryptocurrency Risk Measures? Evidence from Venue Comparison and Stablecoin Micro-Depeg Prediction"**

by S. Aljaloud and W. Alghassab — Heliyon.

All data are retrieved from public exchange APIs. Running the scripts in order reproduces the cleaned datasets, output tables, and figures reported in the paper.

## Data and archive

An archived, citable snapshot of this replication package (code and all processed datasets) is deposited on Zenodo:

> DOI: [10.5281/zenodo.21792917](https://doi.org/10.5281/zenodo.21792917)

Please cite the archive when using the data or code (see `CITATION.cff`).

##  Reproduction

### 1. Install dependencies
```
pip install -r requirements.txt
```

### 2. Pull raw data from exchange APIs
```
python src/pull_binance_daily.py
python src/pull_kraken_daily.py
python src/pull_coinbase_daily.py
```

### 3. Build cleaned panels
```
python src/make_clean_panel_3venues.py
python src/build_depeg_dataset.py
```

### 4. Run analyses
```
python src/plot_spreads_3venues.py
python src/var_comparison.py
python src/volatility_comparison.py
python src/expanding_window_analysis.py
python src/enhanced_ml_analysis.py
python src/usdc_expanding_window.py
python src/plot_system_architecture.py
```

All outputs (CSV tables, PNG figures) are saved to `data/clean/` and `outputs/`.

##  Analysis Code (`src/`)

### Data Collection
- `pull_binance_daily.py` — retrieves Binance daily data via API  
- `pull_coinbase_daily.py` — retrieves Coinbase daily data via API  
- `pull_kraken_daily.py` — retrieves Kraken daily data via API  

### Panel Construction
- `make_clean_panel_3venues.py` — builds cleaned panel across three venues  
- `build_depeg_dataset.py` — constructs the stablecoin micro-depeg panel  
- `config.py` — shared configuration settings  

### Cross-Venue Fragmentation Analysis
- `plot_spreads_3venues.py` — triangular spread and Z-score plots  
- `anomaly_summary.py` — spread anomaly diagnostics  
- `var_comparison.py` — variance decomposition and VaR comparison  
- `volatility_comparison.py` — cross-venue volatility measures  
- `volatility_without_anomalies.py` — volatility excluding anomalies  

### Micro-Depeg Prediction
- `bootstrap_logit_inference.py` — walk-forward bootstrapped inference  
- `logistic_coefficients.py` — logistic coefficient summaries  
- `threshold_robustness.py` — threshold sensitivity analysis  

### Classifier Benchmarking and Expanding-Window Evaluation
- `expanding_window_analysis.py` — expanding-window walk-forward evaluation (all 5 classifiers)  
- `expanding_window_supplementary.py` — threshold robustness and baseline vs interaction specification  
- `enhanced_ml_analysis.py` — ROC/PR curves, SHAP, DeLong tests  

### Cross-Stablecoin Comparison
- `usdc_analysis.py` — USDC descriptive analysis  
- `usdc_comparison.py` — USDC vs USDT comparison  
- `usdc_expanding_window.py` — USDC expanding-window evaluation  

### Visualisation
- `calibration_plot_pub.py` — publication-quality calibration plot  
- `plot_system_architecture.py` — pipeline architecture diagram (Figure 1)  


### Interaction and Cross-Venue Risk Tables
- `interaction_logit_bootstrap.py` — interaction-term coefficients with moving-block bootstrap (Table 9)
- `vol_var_3venues.py` — cross-venue volatility and VaR comparison, three venues (Table 3)

## Major-Revision Analyses (2026)

The `revision2026/` folder contains the analyses added during the Heliyon
major revision, packaged as a single self-contained notebook
(`heliyon_v2_experiments.ipynb`, runnable locally or on Google Colab) with
its result CSVs in `revision2026/outputs/`:

- Corrected full-sample variance shares (Table 2 recomputation)
- Stress-conditional fragmentation: variance shares and spread magnitudes under
  high-volatility regimes, extreme return days, and anomaly days (Table 4)
- Newey-West significance tests for mean cross-venue spreads (Table 1)
- Rolling-window robustness, w in {14, 30, 60} (Table 12)
- Extended micro-depeg threshold sweep, 5-20 bps (Table 11)
- Moving-block bootstrap block-length robustness, L in {7, 14, 21}
- Deviation-distribution context for the 10 bps threshold
